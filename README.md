# Java Full-Stack Course Tasks

A collection of hands-on Java practice programs, coursework exercises, and logic building tasks covering Core Java, control flow, and OOP concepts.

---

## 📂 Programs Included

### 1. Swiggy Food Ordering App (`Swiggyapp.java`)
* **Description:** A console-based food ordering simulation.
* **Concepts Used:** `Scanner` class, nested `switch-case` statements, variable manipulation.
* **Execution:**
  ```bash
  javac Swiggyapp.java
  java Swiggyapp
  ```

---

### 2. OTP Generation & Verification (`otp.java`)
* **Description:** Simulates registered mobile number authentication and generates a random 5-digit verification code.
* **Concepts Used:** Conditional `if-else` branching, `Math.random()` numeric logic, `long` data types.
* **Execution:**
  ```bash
  javac otp.java
  java otp
  ```

---

## 🛠️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone [https://github.com/123Aishu/Java-FullStack-Course-Tasks.git](https://github.com/123Aishu/Java-FullStack-Course-Tasks.git)
   ```
2. Navigate into the folder:
   ```bash
   cd Java-FullStack-Course-Tasks
   ```
3. Compile and run any `.java` file using JDK 8 or higher.
